# arXiv Submission Checklist

## Required Files

- [x] paper source in markdown: `paper.md`
- [x] generated manuscript PDF: `paper.pdf`
- [x] benchmark methodology note
- [x] abstract extracted for metadata entry
- [x] public code repository URL

## Before Upload

- [ ] confirm title exactly as desired
- [ ] confirm author name and affiliation formatting
- [ ] confirm email visibility preference
- [ ] confirm arXiv category selection
- [ ] review PDF formatting one final time

## arXiv Form Fields

Prepare these values in advance:

- title
- abstract
- authors
- comments
- primary category
- cross-lists
- keywords if needed for your own records

## Upload Package Guidance

For the current project state, the simplest path is:

1. upload the manuscript PDF if the chosen arXiv workflow allows your preferred submission mode
2. keep the public code artifact live on GitHub
3. include the repo URL in the abstract comments or submission comments if appropriate

If a source-based workflow is preferred later, convert the paper into a LaTeX-native source package.

## After Submission

- [ ] save arXiv ID in repo docs
- [ ] add arXiv link to README
- [ ] add arXiv link to website article
- [ ] check Google Scholar indexing after publication
