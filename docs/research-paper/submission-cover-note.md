Guardrails as Runtime Policy: An Orchestration Architecture and Evaluation Framework for Reliable Multi-Agent Systems

The project provides:

- the manuscript source and PDF
- the benchmark methodology note
- executable benchmark variants across three runtime configurations
- saved benchmark report artifacts used in the paper narrative

Current scope note:

The present prototype is intentionally narrow and should be understood as a reproducible systems prototype rather than a large-scale production benchmark. Its primary value is that the paper's claims are tied directly to executable code and saved benchmark outputs.
