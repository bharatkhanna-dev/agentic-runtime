# Benchmark Workloads

This directory contains short design notes for the benchmark workloads used by `agentic-runtime`.

These files are not standalone runnable examples. They describe the workload intent behind the saved datasets and evaluation logic in:

- `benchmarks/datasets/`
- `src/agentic_runtime/agents/`
- `src/agentic_runtime/evaluation/`

The current workloads are:

- `support_triage.md`
- `research_assistant.md`

If this repository later adds end-to-end sample apps or demo scripts, those should live under a true `examples/` surface with executable entry points.
